- **`BUG-IAM-01`**: Embedded `<IndiaPhoneInput />` component into the Admin Registration form on `app/login/page.tsx`, defaulting to `+91` with a comprehensive country code dropdown.
- **`BUG-IAM-02`**: Enhanced duplicate registration detection on `app/login/page.tsx`. Identified Supabase behavior where existing emails return an empty `identities: []` array without an active session, presenting an inline error message (`"An account with this email already exists. Please log in."`) rather than navigating to `/verify-email`.
- **`BUG-IAM-03`**: Enforced robust password validation in `handleRegister` using `validatePasswordStrength()` from `lib/security.ts`, blocking weak passwords (digits-only or letters-only) and enforcing minimum 8 characters with letter and number requirements.
- **`BUG-IAM-04`**: Updated `app/register/page.tsx` to redirect to `/login?tab=register`, and added URL search parameter handling on `app/login/page.tsx` to automatically activate the "Register Admin" tab.
- **`BUG-IAM-05`**: Removed legacy references to deleted `/auth/callback` from `supabase.auth.resend` invocations in `app/login/page.tsx` and `app/verify-email/page.tsx`.
- **`BUG-IAM-07`**: Updated `lib/supabase/middleware.ts` to redirect authenticated users directly to their designated portal (`/admin` or `/employee/dashboard`) based on profile role. Converted `app/dashboard/page.tsx` sign-out form to a secure Server Action (`signOutAction`), eliminating 404/405 errors.
