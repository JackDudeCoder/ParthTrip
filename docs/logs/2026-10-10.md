## 1. Work Completed During Session

### Fix Next.js Server Component Import Error (`formatToINR` / `toDDMMYYYY`)
- **Issue Diagnosis**:
  - `app/admin/page.tsx` is an async Server Component rendered on the server during admin login navigation.
  - It imported `formatToINR` from `components/ui/RupeeInput.tsx` and `toDDMMYYYY` from `components/ui/IndiaDatePicker.tsx`.
  - Both of those component files include `'use client'`, causing Next.js to treat all exported functions as Client References and throwing `Attempted to call formatToINR() from the server but formatToINR is on the client`.
- **Resolution**:
  - Created standalone utility module `lib/formatters.ts` containing pure formatting helpers (`formatToINR`, `toDDMMYYYY`, `toISODate`).
  - Re-exported the helpers from `components/ui/RupeeInput.tsx` and `components/ui/IndiaDatePicker.tsx` for backwards compatibility.
  - Updated `app/admin/page.tsx` and `components/trips/EmployeeTripCard.tsx` to import directly from `@/lib/formatters`.
  - Verified project build / type-safety with `npx tsc --noEmit` (0 errors).
